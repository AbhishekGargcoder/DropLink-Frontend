# DropLink  
### Description
DropLink is a web application that allows users to easily share files and links with others. It provides a simple and intuitive interface for uploading files, generating shareable links, and managing shared content. With DropLink, users can quickly and securely share files without the need for complex setups or third-party services.

### Features
- **File Upload**: Users can upload files of various formats and sizes to the platform. 
- **Link Generation**: After uploading a file, DropLink generates a unique shareable link that can be easily shared with others.
- **Link Management**: Users can manage their shared links, including the ability to delete or revoke access to specific links.
- **Secure Sharing**: DropLink ensures that shared files and links are secure, with options for password protection and expiration dates.
- **Cross-Platform Compatibility**: DropLink is accessible from both desktop and mobile devices, allowing users to share files on the go.
- **User-Friendly Interface**: The application features a clean and intuitive interface, making it easy for users to navigate and use the platform.
- **Real-Time Notifications**: Users receive real-time notifications when their shared links are accessed or downloaded.

### Technologies Used
- **Frontend**: React, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express.js, Prisma ORM
- ### Installation
1. Clone the repository: `git clone
2. Navigate to the project directory: `cd DropLink`
3. Install dependencies for the backend: `cd backend && npm install`
4. Install dependencies for the frontend: `cd ../frontend && npm install`
5. Set up the database and configure environment variables as needed.
6. Start the backend server: `cd ../backend && npm start`
7. Start the frontend development server: `cd ../frontend && npm start`
8. Access the application in your web browser at `http://localhost:${process.env.PORT}`.
